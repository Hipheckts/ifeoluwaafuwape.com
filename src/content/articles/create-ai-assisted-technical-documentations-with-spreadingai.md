### NOW, LET'S GET INTO IT!

#### Step 1: Set up a Spreading Account
Go to `https://app.spreading.ai/signup` to sign up. You can quickly sign up with your Google account or email. Once successful, you will be prompted to name your workspace and then redirected straight to your Spreading App Dashboard. 

EASY YEAH 😄!

#### Step 2: Create a New Project
On your dashboard **Team Project** section, click the **Create a Project** button and enter your preferred Project Name.

#### Step 3: Generate a Directory Structure with AI
Once your project is created, click to open it. On the sidebar, click on the **AI Icon — Generate Directory with AI**.

This launches a prompt modal where you choose the type of documentation (e.g. API Reference, User Guide, Architecture Specs) and provide a brief project description (up to 100 characters). Click **Generate**, and Spreading automatically establishes the folder structure with appropriate naming conventions! You can regenerate the output for improved results or click **Apply**.

#### Step 4: Populate Documentation Content
Now that your project is set up with an appropriate folder structure, you can populate your files using two powerful options:

1. **Generate Outline**: Create a structured outline by specifying the documentation type, audience type, and product description. Click **Generate**, and Spreading generates the entire project outline, which you can expand by adding section blocks.
2. **Generate Doc from Code**: Choose your documentation context and target programming language, paste your code snippet into the designated area, and click **Generate**. Spreading automatically synthesizes clean, accurate technical documentation from your raw code:

```typescript
// Example: Code Snippet to AI-Generated Doc Spec
export interface TechnicalDocSpec {
  featureName: string;
  targetAudience: 'Internal Developers' | 'API Consumers';
  architectureOverview: string;
  generatedAt: string;
}
```

Viola! You can do this for every file and then save or publish your documentation.
